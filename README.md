# Object Detection and Tracking

## 📌 Description
This project shows how to detect and track objects in real time using a webcam. It uses YOLOv8 for detecting objects and OpenCV for handling video.

## 🚀 Features
- It captures live video from your webcam .
- Object detection using YOLOv8.
- Detects objects like people, phones, etc....  
- Bounding boxes around detected objects.  
- It assigns a unique ID to track each object.

## 🛠️ Technologies Used
- Python
- OpenCV
- YOLOv8 (Ultralytics)
- NumPy

## ▶️ How to Run
Install required libraries: 
pip install opencv-python ultralytics filterpy numpy  
python object_tracking.py

## 📷 Output
It Detects objects like person, mobile phone with tracking IDs.
